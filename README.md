# Deadlock Detective 💻🔒

An educational Operating Systems diagnostic web tool designed to compute resource allocation safety vectors and identify system deadlocks.

## ✨ Features
- **Banker's Algorithm Implementation:** Simulates OS resource allocation safety checks.
- **Interactive Matrices:** Dynamic input fields for custom process and resource limits.
- **Instant Status Log:** Clear visual indicators for safe vs. unsafe states.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3
- **Logic:** Vanilla JavaScript (ES6+)
